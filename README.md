# tmp

递归扫描一个目录（含其所有子目录）下的视频文件，找出其中刷新率为 60 Hz 的那些。

## 运行

```sh
uv run main.py                  # 交互式：在终端提示输入要筛选的目标目录
uv run main.py /path/to/videos  # 跳过提示，直接筛选指定目录
```

提示符下：

- 直接回车 → 使用当前目录；
- 输入不存在的路径 → 提示重试，不退出；
- `Ctrl+C` / `Ctrl+D` → 取消（退出码 130）。

目标目录下的**所有子目录会被一起递归搜索**，输出与汇总里用相对路径
（如 `movies/deep/clip.mp4`）区分同名文件。

## 判据

视频容器没有独立的“刷新率”字段，对应的是视频流的帧率 (fps)：
60 Hz 即 60 fps，并把 NTSC 的 59.94 fps 也算作 60 Hz（容差 ±0.5）。
帧率通过系统 `ffprobe`（来自 ffmpeg）读取，优先 `avg_frame_rate`，
为 `0/0` 时回退 `r_frame_rate`。

退出码：`0` 正常 / `1` 目录里没有视频 / `2` 参数不是目录或缺少 ffprobe / `130` 取消。
